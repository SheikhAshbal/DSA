## Learning objectives

- Interpret centre, spread, and distribution shape.
- Distinguish robust summaries from extreme-sensitive measures.
- State percentile and standard-deviation conventions.
- Combine numerical summaries with appropriate plots.
- Interpret Pearson correlation and inspect nonlinear relationships.
- Use heatmaps and scatter plots without inferring causation.
