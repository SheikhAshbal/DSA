## Learning objectives

- Assess quality and tidiness before making changes.
- Distinguish structuring, cleaning, and transformation.
- Reshape repeated measurements into tidy form.
- Record decisions and implement reproducible workflows.
- Validate that the resulting data is ready for its intended analysis.
- Justify missing-data treatments and duplicate keys.
- Standardise formats and parse messy text with explicit validation.
