## Learning objectives

- Choose visual channels for the reader's task.
- Distinguish useful chart context from distracting decoration.
- Identify misleading axes, scales, and selections.
- Review charts for accuracy and clarity before publishing.
- Match plot types to questions, variable types, and aggregation levels.
- Combine Seaborn with Matplotlib and identify interactive Plotly use cases.

## Reproducible examples

Run [lesson01-visualization-demo.py](./lesson01-visualization-demo.py) for the bar-length arithmetic. Add --plot to regenerate the [axis-comparison figure](./lesson01-axis-comparison.svg), using the Matplotlib version in [lesson01-requirements.txt](./lesson01-requirements.txt).
